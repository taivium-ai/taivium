Methodology

Dataset Label Schema

The Privacy profile includes the following entity labels:

  • PERSON: Individual names and personal identifiers
  • ORG: Organization and company names
  • LOCATION: Geographic locations (cities, countries, regions)
  • EMAIL: Email addresses
  • PHONE: Telephone numbers
  • API_KEY: API keys and authentication tokens
  • DATE: Dates and temporal expressions
  • IP: IP addresses (IPv4 and IPv6)
  • SOCIALNUMBER: Social security numbers, credit card numbers, cryptocurrency addresses
  • USERNAME: Usernames and login identifiers

Detector Output Mapping

Taivium: Uses native entity labels matching the schema directly.

Presidio: Maps its entity types to the label schema as follows:
